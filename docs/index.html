04 · 维护文档维护方式

本站是静态站点（Astro），源码在GitHub。更新文档的方式：

系统台账、能力清单 → 改 src/config/portal.ts； 本页正文 → 改 src/pages/docs/index.astro。 push 到 main 后由 CI 自动构建部署，国内外环境同源发布。
